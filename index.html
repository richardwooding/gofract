gofract Flatpak repository

A Fractint-style fractal viewer. Source, other packages and documentation: github.com/richardwooding/gofract.

Install

flatpak install --from https://richardwooding.github.io/gofract/gofract.flatpakref

That adds this repository as a remote and installs the app; flatpak update picks up new releases. The runtime comes from Flathub, which must be configured as a remote.
